# THE CHAMBER

벅샷 룰렛의 핵심 의사결정을 브라우저에서 시험하는 프로토타입입니다. CPU 딜러와 혼자 하거나 Convex 방에서 2인이 플레이할 수 있습니다. 실탄과 공포탄의 남은 개수는 공개되지만 순서는 숨겨집니다.

## 실행

```bash
npm install
npx convex dev
```

`npx convex dev`에서 Convex 계정에 로그인하고 프로젝트를 선택하면 개발 배포가 연결됩니다. CLI가 `.env.local`에 `CONVEX_DEPLOYMENT`와 `VITE_CONVEX_URL`을 기록하고 서버 함수를 올립니다. 다음에는 다른 터미널에서 프런트엔드를 실행하세요.

```bash
npm run dev
```

서버 함수를 수정하는 동안에는 `npm run dev:backend`를 계속 실행하세요. 이미 연결된 Convex 배포를 사용하기만 할 때는 `.env.example`을 참고해 `.env.local`에 `VITE_CONVEX_URL`을 설정하면 됩니다. 개발 배포 URL은 Convex 대시보드에서도 확인할 수 있습니다. `VITE_CONVEX_URL`이 없으면 CPU 딜러 모드만 실행됩니다.

`.env.local`과 그 밖의 `.env` 파일은 Git에서 제외됩니다. `VITE_`로 시작하는 값은 브라우저에 포함되므로 비밀 키를 넣지 마세요. Convex 서버 함수에서 사용할 비밀 값은 Convex 대시보드의 해당 배포 환경 변수에 설정해야 합니다.

`npm test`, `npm run lint`, `npm run build`로 규칙, 서버 타입, 프런트엔드 빌드를 확인할 수 있습니다.

## 배포 환경 변수

프런트엔드를 정적 호스팅에 배포할 때는 호스팅 서비스의 빌드 환경 변수에 `VITE_CONVEX_URL`을 설정하세요. 실제 서비스에는 Convex **프로덕션 배포 URL**을 사용하고, 백엔드 코드도 `npx convex deploy`로 프로덕션에 배포해야 합니다. 현재 로컬 설정의 `blessed-bat-695`는 개발 배포이므로 서비스용 URL로 사용하지 마세요. 호스팅 환경에서 `npx convex deploy --cmd 'npm run build'`를 빌드 명령으로 쓰는 경우, Convex CLI가 빌드 과정에 프로덕션 URL을 전달합니다. 자동 배포에는 Convex 대시보드에서 발급한 `CONVEX_DEPLOY_KEY`도 호스팅 서비스의 비밀 환경 변수로 설정해야 합니다.

## 2인 멀티플레이

1. 화면 위의 **2인 멀티**를 누르고 이름을 적어 방을 만듭니다.
2. 표시된 6자리 초대 코드 또는 링크를 다른 플레이어에게 보냅니다.
3. 두 사람이 **준비하기**를 누르면 게임이 시작됩니다.
4. 발사, 아이템, 상자 지급, 재대결이 두 화면에 실시간으로 반영됩니다.

Convex 서버가 방과 턴, 탄환 순서, 아이템 지급, 피해 계산을 관리합니다. 각 참가자에게는 공개 탄환 개수와 자신의 돋보기·버너폰 결과만 전달합니다. 플레이어 키는 탭의 `sessionStorage`에 저장되어 같은 탭을 새로고침하면 방으로 돌아옵니다. 탭을 닫은 뒤 복귀하는 계정 기능, 턴 제한 시간, 연결 이탈 처리는 아직 없습니다.

클라우드 개발 배포는 연결되어 있지만 웹 화면은 현재 로컬 주소에서 실행됩니다. 다른 기기에서 플레이하려면 빌드한 프런트엔드도 접근 가능한 주소에 배포해야 합니다.

## 현재 들어간 규칙

- 자신에게 공포탄을 쏘면 턴을 유지합니다. 다른 발사는 턴이 넘어갑니다.
- 발사 대상을 고르면 총구가 그쪽으로 돌아간 뒤 발사하며, 실탄에는 섬광과 반동이 나타납니다.
- 실탄은 체력 1을 줄이고, 톱을 쓴 다음 실탄은 체력 2를 줄입니다.
- 첫 장전에는 아이템 없이 시작하며, 실탄 1발과 공포탄 3발이 들어갑니다.
- 탄환을 모두 쓰면 새로 장전하고 아이템 상자를 열어 양쪽에 무작위 아이템을 두 개씩 지급합니다.
- 아이템은 돋보기, 맥주, 톱, 담배, 수갑, 버너폰, 인버터, 유통기한 약, 아드레날린 9종입니다. 같은 아이템도 각각 별도 슬롯에 들어가며 사용할 때 한 개만 소비됩니다.
- 한쪽 체력이 0이 되면 게임이 끝납니다.

이 프로토타입은 원작의 전체 규칙과 밸런스를 재현하지 않습니다. 디자인 방향과 온라인 플레이 설계는 [DESIGN.md](./DESIGN.md)에 정리했습니다.
